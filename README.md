- NextJS 15

## API

- GET /api/dashboard/articles  → returns a list of articles
- GET /api/dashboard/articles/{id} → returns a specific article
- POST /api/dashboard/articles → creates a new article
- PUT /api/dashboard/articles/{id} → updates a specific article
- DELETE /api/dashboard/articles/{id} → deletes a specific article
